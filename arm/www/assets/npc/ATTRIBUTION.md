# Office NPC sprites

Source: **Office Beat them all pack** by Naarshakta, with collaborators
Icedman and Rich_Uncle_Bloodmoney.

- https://opengameart.org/content/office-beat-them-all-pack
- License: CC-BY 3.0 (https://creativecommons.org/licenses/by/3.0/)

Files used: `people_1.png` … `people_6.png`, `people_boss.png`.
Only the first 32×32 standing frame is used; the rest of each sheet is left
untouched in the source pack. `npc_sheet.json` maps that frame to the ARM
overview renderer.
