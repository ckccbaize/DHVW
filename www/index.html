QQ 官方 Bot 登录与链接指引

遵循 QQ 开放平台规范，不扫码登录个人号，而是接入官方 Bot APIv2（单聊 + 图片多模态 + 表情包）。

  1. 登录 QQ 开放平台 https://q.qq.com 创建机器人应用，在「开发管理」复制 AppID 与 ClientSecret。
  2. 在「能力配置」开通单聊（C2C）消息，并在「沙箱配置」添加你的 QQ 号（"sandbox": true）。
  3. 给测试机器人私聊发一条消息，从日志获取你的单聊 user_openid，填入 ownerOpenId 白名单。
  4. 配置设备端 /etc/dhvw/qqbot.json（设 "followBoost": true 或 "enabled": true）并执行 sudo systemctl enable --now dhvw-qqbot.service。
{
  "enabled": false,
  "followBoost": true,
  "appId": "你的AppID",
  "clientSecret": "你的ClientSecret",
  "sandbox": true,
  "ownerOpenId": "你的单聊user_openid",
  "listenAddr": "127.0.0.1:8088",
  "shellUrl": "http://127.0.0.1:8080",
  "stateDir": "/var/lib/dhvw/qq-openclaw"
}
